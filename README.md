# PROBLEMA EN EMPRESA DE EVENTOS
* Una casa de eventos ha realizado 400 eventos a lo largo de su historia (5 años), ellos nos dan un dataset en el cual se encuentran sus eventos realizados hasta la fecha. Sucede que ellos han presentado una serie de fallas e inconvenientes en sus eventos y no han cumplido con un buen nivel de satisfacción al cliente. Nos están solicitando que definamos como ellos pueden reducir el porcentaje de inconvenientes o incumplimiento con sus clientes.

Esto como lo hacemos:

1. Revisamos el dataset para poder conseguir datos como los tipos de problemas que presenta hoy en día la empresa y con que frecuencia dichos problemas suceden en sus eventos. Esto se usa para definir con qué eventos (en este caso problemas) se trabajar el teorema de pareto, para así definir cuáles son los principales problemas que hacen que los eventos no cumplan con su cometido (revisar que es el diagrama y teorema de pareto)
2. Una vez definidos estos problemas mediante el método de ishikawa se revisaran las causas potenciales de que este problema(s) suceda para así dar una solución factible a los mismos.
3. Tras eso se mostrará mediante un gráfico de control y un diagrama de dispersión en que períodos de tiempo (en meses) se presentaron mas fallas y que variable define la frecuencia de este problema (variable dependiente), esto asignado respectivamente.
4. Al final se dara una conclusion de cual o cuales son los principales problemas que hacen que los eventos no salgan como se espera, que se puede hacer para solventar esos mismos y el porcentage de mejora que se tendra, en cuanto a la satisfaccion del cliente, al resolver esto.
